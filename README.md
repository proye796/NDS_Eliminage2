| 제라 이벤트 이상 동작 | 아이템 선택을 건너뛰고 부적합 대사가 나오거나, 바로크 포트에서 반응이 없다는 보고가 있습니다. |
| 소환 뒤 공격 누락 | 소환으로 적이 늘어난 뒤 공격하지 않는 경우가 있다는 보고가 있습니다. 이도류 수정과는 별개입니다. |

프리즈가 나면 소프트 리셋도 되지 않는다는 보고가 있습니다. 자주 저장하세요.
